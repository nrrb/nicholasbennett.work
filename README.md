# Nicholas Bennett

Single-page Technical Customer Success website built with Vue 3, Tailwind CSS, and Vite SSG.

## Development

Run `npm ci`, then `npm run dev`. Validate with `npm run build`.

## Routes

`/` is the sole page. Retired `/cs`, `/eng`, `/dev-preview`, and `/version1`–`/version3` URLs redirect to `/` through Vercel.

## Release workflow

`main` is canonical. Review future work on short-lived branches and Vercel previews before merging. Production promotion remains deliberate. The homepage release was authorized by Nicholas on November 15, 2026.
