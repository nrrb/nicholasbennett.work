# Deployment policy

The live site must remain a parking page. Do not publish or deploy draft copy, merge work to release it, or re-enable Vercel Git deployments unless Nicholas explicitly asks to publish a finished replacement. Keep git.deploymentEnabled false in vercel.json on every branch. Develop and preview draft content locally. Preserve the customer success writing scaffold for continued editing.

Use `/dev-preview` for the preserved writing scaffold during local development. Keep `/`, `/cs`, and `/eng` parked. The preview route must not be published without an explicit instruction from Nicholas.
